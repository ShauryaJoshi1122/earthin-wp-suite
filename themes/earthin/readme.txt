Ultra-lightweight, high-performance, and responsive multi-purpose WordPress theme built for speed, SEO, and full compatibility with Earthin Page Builder and Gutenberg.

== Description ==

Earthin is a modern, performance-first WordPress theme designed to deliver 100/100 Google PageSpeed scores out of the box. Featuring a total CSS/JS footprint under 20KB, zero jQuery, semantic HTML5 markup, and native Theme Customizer controls, Earthin serves as an alternative to Astra and GeneratePress.

Features:
* Ultra-lightweight footprint (< 20KB total assets).
* Built for full compatibility with Earthin Suite, Earthin Page Builder, and WooCommerce.
* Native WordPress Customizer controls for colors, typography, container width, and footer text.
* 100% accessible with skip links, ARIA labels, and keyboard navigation.
* Responsive multi-column layout with flexible sidebar positioning.
* Clean, sanitized code adhering to 100% of WordPress Theme Review guidelines.

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes > Add New.
2. Click 'Upload Theme' and choose the `earthin` ZIP archive.
3. Click 'Install Now' and then 'Activate'.
4. Customize colors and layout via Appearance > Customize > Earthin Global Settings.
