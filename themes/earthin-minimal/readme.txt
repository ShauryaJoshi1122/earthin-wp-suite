Ultra-fast, distraction-free minimalist WordPress theme designed for writers, journalists, and modern bloggers with reading progress tracking and pure CSS dark mode.

== Description ==
Earthin Minimal focuses entirely on typography, readability, and blazing speed. It boasts 100/100 Core Web Vitals, zero bloated third-party frameworks, built-in reading progress indicator, dark mode toggle, and complete mobile responsiveness.

== Installation ==
1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the earthin-minimal.zip file.
3. Click Install Now and then Activate.
