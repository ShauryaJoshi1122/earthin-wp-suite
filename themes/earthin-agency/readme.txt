Sleek, high-impact corporate agency and SaaS startup theme featuring dark-mode bento grids, interactive case studies, lead capture forms, and high-conversion landing page layouts.

== Description ==
Earthin Agency is engineered for digital studios, software agencies, and high-growth SaaS firms. Features cyber-dark aesthetic, modern bento grid layouts, interactive client metrics, case study portfolios, and strategic consultation booking CTAs.

== Features ==
* Dark-modern bento grid layout
* Live performance metrics counter
* Featured work & case study showcase
* High-conversion discovery booking CTA
* Responsive WCAG AAA compliant styling

== Installation ==
1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose earthin-agency.zip.
3. Click Install Now and Activate.
