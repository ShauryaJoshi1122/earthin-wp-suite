## Overview
Earthin Code Snippets provides an interface to write, test, and manage custom PHP, CSS, and JavaScript snippets directly from the WordPress administrative panel.

## Key Features
- Scope selector: run snippets site-wide, frontend-only, or backend-only.
- Safe execution trap: catches throwable exceptions and auto-deactivates offending scripts.
- Clean header/footer injection for custom tracking tags and styling rules.
- Fast toggle switches without removing code snippets.
