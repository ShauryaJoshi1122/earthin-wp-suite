## Overview
Earthin Sticky Header improves on-page user engagement by keeping navigation headers accessible during vertical scroll, alongside a reading completion progress bar and smooth scroll-to-top button.

## Key Features
- High performance CSS3 slide-down transition.
- Pure vanilla JavaScript with passive scroll listeners.
- Integrated horizontal reading progress bar.
- One-click back to top floating button.
