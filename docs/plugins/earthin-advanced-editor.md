## 1. Overview

Earthin Advanced Editor unlocks hidden formatting capabilities within WordPress's classic TinyMCE editor, providing font family pickers, custom point sizing, text highlighting, and role-based toolbars.

---

## 2. Real Features Implemented

* **Toolbar Formatting Buttons**:
  * Font family picker (`fontselect`)
  * Font size dropdown (`fontsizeselect`)
  * Background highlight color picker (`backcolor`)
  * Underline button (`underline`)
  * Full text justify (`alignjustify`)
  * Subscript & Superscript (`sub`, `sup`)
* **Custom Typography Sizing**: Configurable space-separated font size increments via `tiny_mce_before_init`.
* **Role-Based Restrictions**: Restrict advanced typography controls to Administrators and Editors only.
