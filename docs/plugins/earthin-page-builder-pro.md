## 1. Overview & Architecture

Earthin Page Builder Pro is the commercial extension for Earthin Page Builder, adding conversion-focused marketing modules and professional styling presets.

## 2. Pro Modules

- **Pricing Comparison Tables**: Clean multi-tier pricing cards with customizable feature items and checkout action links.
- **Testimonial Boxes**: Verified customer quotes with author badges and subtle accent borders.
- **Performance Guarantee**: All Pro blocks render with lightweight CSS and zero external JavaScript dependencies.
- **Parent Plugin Guard**: Verifies that the free `Earthin_Page_Builder` base plugin is installed and activated.
