## 1. Overview

Earthin Classic Editor restores the classic TinyMCE WordPress edit screen with comprehensive controls for default editor selection, post type filtering, and author-level dual editor switching.

---

## 2. Real Features Implemented

* **Default Editor Preference**: Select either Classic Editor or Block Editor as the primary site default.
* **Dual Editor Switching**: Enables authors to choose between "Edit (Classic)" and "Edit (Block)" directly from post listing tables.
* **Granular Post Type Support**: Enable or disable the classic editor per post type (Posts, Pages, or custom post types).
* **Official WordPress Filters**: Integrates with `use_block_editor_for_post_type` and `use_block_editor_for_post`.
