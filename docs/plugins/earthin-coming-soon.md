## Overview
Earthin Coming Soon presents public visitors with a modern launch splash page featuring a real-time countdown clock and lead capture box, while giving developers and clients full site preview access.

## Key Features
- Dynamic client-side countdown timer calculating days, hours, and seconds.
- Native email lead capture saving subscribers directly to WordPress database.
- Secret bypass key URL query (`?earthin_preview=...`) allowing clients to review staging without user credentials.
- Automatic 503 response header option preventing premature indexing of unfinished pages.
