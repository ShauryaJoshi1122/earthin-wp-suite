## Overview
Earthin Security 2FA equips WordPress websites with hardware-token-grade Two-Factor Authentication using RFC 6238 TOTP protocols, stopping unauthorized administrative logins.

## Key Features
- Native PHP implementation of RFC 6238 TOTP with time drift compensation (+/- 30s).
- Instant QR setup for Google Authenticator, Authy, and 1Password.
- 5 unique one-time recovery scratch codes stored securely.
- Login screen interception before session authentication cookies are issued.
