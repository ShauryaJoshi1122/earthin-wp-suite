## 1. Overview

Earthin White Label allows agencies and administrators to rebrand the WordPress login portal and declutter client administration dashboards without editing core files.

---

## 2. Real Features Implemented

* **Custom Login Screen**:
  * Custom login logo image URL and custom destination hyperlink.
  * Custom login background color.
* **Dashboard Widget Control**:
  * Hide "WordPress Events and News" widget.
  * Hide "Quick Draft" widget.
  * Hide "Activity" widget.
  * Hide "At a Glance" widget.
* **Administrative Footer Customization**:
  * Custom agency footer credit text.
  * Security-conscious concealment of WordPress core version numbers.
* **100% Core Safe**: Cleanly hooks into standard filters with zero core file modifications.
