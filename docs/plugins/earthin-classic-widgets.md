## 1. Overview

Earthin Classic Widgets restores the traditional WordPress widget administration screen and Customizer widgets panel by safely unhooking the block-based widget editor.

---

## 2. Real Features Implemented

* **Block Widgets Disablement**: Integrates with the official WordPress `use_widgets_block_editor` filter to restore classic widget panels.
* **Administrative Toggle**: Easy checkbox control under **Settings > Earthin Widgets** allowing administrators to toggle classic vs block widgets.
* **Safe Fallback**: Deactivating or disabling restores standard Gutenberg block widgets with zero database contamination.
