## Overview
Earthin Form Builder provides a clean form engine that lets website owners embed lead generation and contact forms with automated anti-spam filtration and dashboard record storage.

## Key Features
- Simple shortcode syntax `[earthin_form id="..." title="..."]`.
- Invisible honeypot field blocking automated spam bots.
- Native database persistence for inquiries.
- Direct administrative email notifications with visitor Reply-To headers.
