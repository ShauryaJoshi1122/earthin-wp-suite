## Overview
Earthin WP Activity Log gives website owners a comprehensive security audit trail, logging administrative logins, brute-force attempts, post publishing, and plugin state transitions.

## Key Features
- Records user authentications, logouts, and failed credential attempts.
- Tracks post lifecycle updates and deletions.
- Records plugin activations and deactivations.
- Captures client IP addresses and UTC timestamps.
- Zero external database queries; fast rolling buffer.
