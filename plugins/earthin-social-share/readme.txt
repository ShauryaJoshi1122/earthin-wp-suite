Fast, privacy-focused social sharing buttons for WordPress with zero external tracking scripts, clean SVG styling, and shortcode support.

== Description ==

Earthin Social Share adds clean, lightweight social sharing links to your WordPress posts and pages without loading slow third-party JavaScript or invasive tracking cookies.

### Features
* **Zero External Scripts**: 100% pure HTML and CSS with official sharing intent links. Zero tracking pixels or cookies.
* **Supported Networks**: X (Twitter), Facebook, LinkedIn, WhatsApp, Telegram, Reddit, and direct Email.
* **Flexible Placement**: Place buttons above content, below content, both, or manually using the `[earthin_social_share]` shortcode.
* **Granular Post Types**: Selectively display buttons on Posts, Pages, or custom post types.
* **Blazing Fast**: Extremely lightweight and completely un-render-blocking.

Developed by Shaurya Joshi for the Earthin ecosystem.

== Installation ==

1. Upload `earthin-social-share` to `/wp-content/plugins/`.
2. Activate via WordPress **Plugins** screen.
3. Configure enabled networks and placement in **Settings > Social Share**.
