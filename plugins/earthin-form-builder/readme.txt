Lightweight, responsive form builder with honeypot spam prevention, email notifications, and in-dashboard entry management.

== Description ==

Earthin Form Builder provides clean, responsive forms with zero bloat. It features honeypot spam filtering that blocks bots without requiring frustrating CAPTCHAs, email notifications to administrators, and in-dashboard submission review.

Features:
* Shortcode integration: `[earthin_form id="contact" title="Contact Us"]`.
* Silent honeypot spam protection.
* Secure nonce validation and input sanitization.
* Email notifications with custom Reply-To headers.
* In-dashboard submission storage and management.

== Installation ==

1. Upload `earthin-form-builder` to `/wp-content/plugins/`.
2. Activate via 'Plugins' in WordPress.
3. Paste `[earthin_form id="contact"]` into any page or post.
