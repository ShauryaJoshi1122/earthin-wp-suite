Premium add-on for Earthin Cookie Consent adding Geo-Targeting rules, verifiable consent audit trails, and deep styling customization.

== Description ==

**Earthin Cookie Consent Pro** empowers businesses to maintain rock-solid compliance proof. It records anonymized proof-of-consent logs, applies geo-targeting to display notices only to visitors in relevant jurisdictions, and provides styling tools.

### Key Features

* **Consent Audit Trails**: Securely store hashed timestamps and decision logs for regulatory audits.
* **Jurisdiction Targeting**: Option to target EU/UK visitors while sparing other regions unnecessary banners.
* **Custom Styling & CSS**: Perfectly blend cookie banners with your theme design.
* **Requires Core**: Requires the free Earthin Cookie Consent plugin.

== Installation ==

1. Ensure Earthin Cookie Consent (free) is installed and active.
2. Upload `earthin-cookie-consent-pro` to `/wp-content/plugins/`.
3. Activate the plugin via WordPress Plugins menu.
4. Manage advanced features under Settings -> Cookie Consent Pro.
