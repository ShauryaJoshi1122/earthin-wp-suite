Ultra-fast, bloat-free visual page builder for WordPress with clean semantic HTML and modular layout blocks.

== Description ==

**Earthin Page Builder** is built from the ground up for speed, simplicity, and performance. Create professional landing pages, clean sales copy, and structured articles without the massive DOM tree bloat and slow load times common to other page builders.

### Key Features

* **High Performance**: Renders clean, semantic HTML with zero inline script overhead.
* **Modular Blocks**: Headings, text paragraphs, call-to-action buttons, and alert callouts.
* **Non-destructive**: Toggle the builder on or off at any time without destroying your native WordPress post content.
* **Developer Extensible**: Easily add custom widgets using the `earthin_pb_render_custom_block` filter hook.

== Installation ==

1. Upload `earthin-page-builder` to `/wp-content/plugins/`.
2. Activate via WordPress Plugins menu.
3. Edit any post or page and scroll down to the Earthin Visual Layout Builder box.
