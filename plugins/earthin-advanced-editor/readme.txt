Unlocks advanced formatting buttons, custom typography controls, and role-based toolbars in the WordPress Classic Editor.

== Description ==

Earthin Advanced Editor unlocks hidden formatting capabilities within WordPress's TinyMCE classic editor.

### Features
* **Font Family & Size Controls**: Easily select font families and customizable point/pixel sizes.
* **Text Highlighting**: Background color picker for highlighting crucial passages.
* **Subscript and Superscript**: Format chemical formulas, mathematical citations, and footnotes.
* **Full Text Justification**: Apply clean justify-alignment across paragraphs.
* **Role-Based Configuration**: Restrict advanced tools to administrators and editors if desired.

Developed by Shaurya Joshi for the Earthin ecosystem.

== Installation ==

1. Upload `earthin-advanced-editor` to `/wp-content/plugins/`.
2. Activate via WordPress **Plugins** screen.
3. Configure toolbar buttons in **Settings > Advanced Editor**.
