== Description ==

**Earthin Chat Connect** provides an elegant, fast, and privacy-respecting floating contact button for WordPress. Enable visitors to launch conversations on WhatsApp, Telegram, direct phone call, or email in a single tap.

### Key Features

* **Multi-channel support**: WhatsApp, Telegram, direct click-to-call, and email.
* **Smart layout**: When only 1 channel is configured, clicking directly launches the app. When multiple channels are active, an interactive menu appears.
* **Zero external trackers**: No third-party tracking scripts, cookies, or external analytics loaded.
* **Fully customizable**: Set position (bottom-right / bottom-left), custom brand colors, and welcoming callout text.
* **High performance**: Pure lightweight HTML and CSS with minimal inline JavaScript.

== Installation ==

1. Upload the `earthin-chat-connect` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure your phone number or chat handles under Settings -> Chat Connect.

== Frequently Asked Questions ==

= Does this plugin send user data to third parties? =
No. It creates direct protocol links (wa.me, t.me, tel, mailto) without any intermediate tracking.
