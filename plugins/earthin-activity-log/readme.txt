Real-time security audit trail monitoring user authentications, content modifications, and plugin status changes.

== Description ==

Earthin WP Activity Log provides security awareness by recording who logged in, who published or edited posts, failed login attempts, and which plugins were activated or deactivated.

Features:
* Real-time monitoring of user logins, logouts, and brute-force failed attempts.
* Content modification auditing (post creation, updates, and deletions).
* Plugin lifecycle monitoring (activations, deactivations).
* Client IP address logging and timestamp recording.
* In-dashboard searchable event viewer with rolling 1000-event memory.

== Installation ==

1. Upload `earthin-activity-log` to `/wp-content/plugins/`.
2. Activate via 'Plugins' in WordPress.
3. Access 'Tools' > 'Earthin Activity Log' to view your audit log.
