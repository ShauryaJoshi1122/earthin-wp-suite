Professional widgets and high-converting marketing components for Earthin Page Builder.

== Description ==

**Earthin Page Builder Pro** unlocks advanced marketing blocks for high-converting landing pages: pricing comparison tables, testimonials, and refined styling presets.

### Key Features

* **Conversion-Driven Blocks**: Sleek pricing tables and testimonial callout cards.
* **Pure Performance**: Clean CSS styling with no bloated JavaScript bundles.
* **Requires Core**: Requires the free Earthin Page Builder plugin.

== Installation ==

1. Ensure Earthin Page Builder (free) is installed and active.
2. Upload `earthin-page-builder-pro` to `/wp-content/plugins/`.
3. Activate via WordPress Plugins menu.
