== Description ==

Earthin Coming Soon provides a sleek, responsive splash page while your site is being designed or updated. Non-logged-in visitors see an animated countdown timer and lead generation form, while administrators and authorized clients browse the site normally.

Features:
* Live countdown timer calculating days, hours, minutes, and seconds.
* Built-in email subscription capture stored safely in the database.
* Secret client preview URL bypass parameter with cookie authentication.
* Optional HTTP 503 Service Unavailable header for search engine safety.
* Dark-mode responsive aesthetic with zero external stylesheet dependencies.

== Installation ==

1. Upload `earthin-coming-soon` to `/wp-content/plugins/`.
2. Activate via 'Plugins' in WordPress.
3. Configure launch date and activate under 'Settings' > 'Earthin Coming Soon'.
