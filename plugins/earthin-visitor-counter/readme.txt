Lightweight, self-hosted, privacy-first website traffic counter and visitor statistics without third-party cookies or cloud trackers.

== Description ==

**Earthin Visitor Counter** gives you clear, real-time website analytics directly on your WordPress server. Track daily unique visitors, total pageviews, and your top performing pages without sending your visitor data to third-party tech giants.

### Key Features

* **100% GDPR Compliant**: No cookies are set for visitors, and IP addresses are securely salted and hashed.
* **Smart Bot Filtering**: Automatically ignores web crawlers, search engine spiders, and automated scrapers.
* **Admin Dashboard Widget**: See today's visitor summary as soon as you log into WordPress.
* **Front-end Shortcodes**:
  * `[earthin_visitor_counter]` - Display all-time website visitor count in widgets or footer.
  * `[earthin_page_views]` - Display read counts on single posts or articles.
* **Fast and Lightweight**: Optimized indexed database queries designed for maximum performance.

== Installation ==

1. Upload `earthin-visitor-counter` to `/wp-content/plugins/`.
2. Activate via WordPress Plugins menu.
3. Access your traffic dashboard under Visitor Stats in the WordPress admin menu.
