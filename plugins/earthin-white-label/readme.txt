Clean, reversible branding controls to customize the WordPress login screen, dashboard widgets, and administrative footer.

== Description ==

Earthin White Label enables administrators and agencies to deliver a clean, customized, and branded WordPress administration portal to their clients.

### Features
* **Login Branding**: Replace the default WordPress logo and link on `wp-login.php` with your own company logo and custom background color.
* **Tidy Client Dashboard**: Remove distracting default widgets such as WordPress Events & News, Quick Draft, and Activity.
* **Custom Admin Footer**: Replace the standard WordPress credit text with your customized agency footer.
* **Version Concealment**: Hides the WordPress core version number in the bottom right admin footer.
* **100% Core Safe**: Never touches or modifies WordPress core files; changes are completely reversible.

Developed by Shaurya Joshi for the Earthin ecosystem.

== Installation ==

1. Upload `earthin-white-label` to `/wp-content/plugins/`.
2. Activate via WordPress **Plugins** screen.
3. Access **Settings > White Label** to configure your branding assets.
