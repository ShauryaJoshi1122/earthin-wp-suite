Smooth sticky header on scroll, scroll-to-top button, and animated reading progress bar with zero external dependencies.

== Description ==

Earthin Sticky Header keeps your navigation bar visible as visitors scroll down long articles, reducing bounce rates and improving navigation. It also includes an animated reading progress bar and back-to-top button.

Features:
* Sticky navigation with smooth slide-down animation.
* Configurable CSS selector matching any WordPress theme.
* Reading progress bar with customizable brand color.
* Floating scroll-to-top button.
* Zero jQuery, pure vanilla JavaScript under 2KB.

== Installation ==

1. Upload `earthin-sticky-header` to `/wp-content/plugins/`.
2. Activate via 'Plugins' in WordPress.
3. Configure settings under 'Settings' > 'Earthin Sticky Header'.
