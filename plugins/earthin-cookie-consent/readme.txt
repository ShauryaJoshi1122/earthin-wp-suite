Lightweight, modern GDPR, ePrivacy, and CCPA compliant cookie consent banner with granular categories and dynamic script blocking.

== Description ==

**Earthin Cookie Consent** gives your WordPress site total compliance with European and global privacy laws (GDPR, ePrivacy Directive, CCPA). Present users with an intuitive, stylish notice banner, granular consent categories, and auto script activation.

### Key Features

* **Complete Legal Compliance**: Supports Accept All, Reject Non-Essential, and granular preferences.
* **Granular Categories**: Necessary, Analytics, Marketing, and Functional cookie controls.
* **Smart Script Execution**: Automatically delays third-party scripts until corresponding consent is granted.
* **Fully Responsive**: Dark and Light themes with bottom bar, top bar, or bottom-right floating box positions.
* **Zero Cloud Lock-in**: All settings and user preferences reside entirely inside your WordPress installation.

== Installation ==

1. Upload the `earthin-cookie-consent` folder to `/wp-content/plugins/`.
2. Activate via WordPress Plugins menu.
3. Configure settings in Settings -> Cookie Consent.
4. Optional: Add `[earthin_cookie_settings]` to your privacy policy page to let users reopen preference settings.
