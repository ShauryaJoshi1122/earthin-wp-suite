Enables the WordPress Classic Editor and TinyMCE writing experience with per-post-type and user-level editor controls.

== Description ==

Earthin Classic Editor restores the traditional WordPress editing screen and TinyMCE rich text editor.

### Features
* **Global Editor Choice**: Set Classic Editor or Block Editor as the primary default.
* **Dual Editor Switching**: Allows authors to seamlessly choose between "Edit (Classic)" and "Edit (Block)" on individual posts.
* **Granular Post Type Support**: Enable or disable the classic editor per post type (e.g. Posts, Pages, custom post types).
* **Official API Integration**: Uses standard WordPress `use_block_editor_for_post_type` and `use_block_editor_for_post` filters.

Developed by Shaurya Joshi for the Earthin ecosystem.

== Installation ==

1. Upload `earthin-classic-editor` to `/wp-content/plugins/`.
2. Activate via WordPress **Plugins** screen.
3. Configure settings in **Settings > Earthin Editor**.
