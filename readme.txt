A modular WordPress management suite by Earthin.

== Description ==
Version 0.1.0 provides the plugin bootstrap, module registry, administrator settings screen, and initial SEO and Social Preview module scaffolds. The feature modules do not yet generate frontend metadata.

== Installation ==
1. Upload the plugin folder to the WordPress plugins directory.
2. Activate Earthin WP Suite.
3. Open Earthin Suite in the admin menu.
